# FairLens

## Features

- AI-powered blind resume screening with automatic anonymization of names, gender, photos, and other personal identifiers.
- Resume parsing with skill extraction, project analysis, ATS compatibility scoring, and candidate comparison.
- Gender Equity Dashboard with workforce diversity, hiring trends, and leadership representation analytics.
- Pay Equity Audit to identify salary disparities across departments, roles, and experience levels.
- Performance Review Analysis to detect potential bias and monitor fairness in employee evaluations.
- Promotion Fairness Analytics to track promotion rates, career progression, and advancement disparities.
- Anonymous workplace reporting system for harassment, discrimination, and other workplace concerns.
- HR Dashboard with real-time equality metrics, alerts, and actionable insights.
- Employee Dashboard for profile management, attendance tracking, promotion readiness, and secure communication with HR.
- Compliance and regulatory reporting with downloadable fairness scorecards and audit summaries.
- Interactive analytics and visualizations to support transparent, data-driven HR decision-making.
